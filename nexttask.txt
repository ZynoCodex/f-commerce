Now let me check if Playwright browsers are installed and what they need.</think>## Manual E2E Test Instructions

Here are the steps to run the E2E tests for the customers feature:

Prerequisites

1. Node.js 22 and npm 10 (the project requires these exact versions)
2. MongoDB replica set running locally or accessible via conne
3. Playwright browsers installed

Step 1: Install dependencies (if not done yet)

npm ci

Step 2: Install Playwright browsers

npx playwright install

Step 3: Configure MongoDB

The E2E tests require a MongoDB replica set for transactions. You have two options:

Option A: Use MongoDB Memory Server (simpler, for testing)
The backend tests already use this, and the dev server can use needed if MONGODB_URI is already configured.

Option B: Run a local replica set
# Download MongoDB Community Server if not installed
# Start a single-node replica set
mongod --replSet rs0 --port 27017 --dbpath /tmp/mongodb

Then in another terminal:
mongo --port 27017
In the mongo shell:
rs.initiate()

Step 4: Start the development servers

From the project root:
npm run dev

This starts:
- Backend on port 4000
- Frontend on port 3000

Wait until both servers report they are ready (health check passes).

Step 5: Run the E2E tests

From the project root:
npm run e2e --workspace @f-commerce/frontend

Or specifically for customers:
npx playwright test customers.spec.ts --workspace @f-commerce/frontend

Step 6: What to expect

The E2E tests verify:
- Archive flow (AC-8): Customer can be archived, shows "Archivarch
- Restore flow (AC-9): Archived customer can be restored, reappears in search
- Duplicate against archived (AC-3): Creating with an archivedre option
- Timeout recovery: Archive timeout triggers reload and shows committed state

Troubleshooting

If tests fail with "Cannot find server"
- Ensure both dev servers are running before running tests
- Check port 3000 and 4000 are not blocked

If tests fail with authentication errors
- The tests auto-signup owners; ensure the backend is fully in

If MongoDB errors occur
- Verify replica set is running or MONGODB_URI points to a valid instance

Clean up after testing

Stop the dev servers when done:
# Press Ctrl+C in the terminal running npm run dev
